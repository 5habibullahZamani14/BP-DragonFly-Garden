# 06.1 - GITHUB UPDATES

> **This guide is for COMPLETE BEGINNERS. We will explain EVERYTHING step by step. This shows you how to update from GitHub.**

---

## 🤔 WHAT IS GITHUB?

GitHub is a website that stores the restaurant system code.

- **Think of it like:** Google Drive for code
- **The manager uploads updates there**
- **You download updates from there**

---

## 🔄 METHOD 1: UPDATE FROM MANAGER DASHBOARD

### What to do:
1. **Open the restaurant system**
   - On Pi: `http://10.42.0.1:5000`
   - On Laptop: `http://localhost:5000`

2. **Login as manager**
   - Click "Manager Login"
   - Enter username and password

3. **Go to Settings → System**
   - Click "Settings" in the menu
   - Click "System"

4. **Check for updates**
   - Click "Check for Updates"
   - If an update is available, you'll see:
     - "New version available: abc123"
     - "Current version: def456"

5. **Click "Update Now"**
   - This downloads and installs the update
   - Wait 5-10 minutes
   - The system will restart automatically

6. **When done**
   - You'll see: "System updated successfully!"
   - Refresh the page

---

## 💻 METHOD 2: UPDATE FROM COMMAND LINE

### What to do:
1. **Open Terminal**
   - On Pi: Click the black square icon
   - On Laptop: Open Command Prompt

2. **Go to the project folder**
   - On Pi:
   ```bash
   cd /home/pi/BP-DragonFly-Garden
   ```
   - On Laptop:
   ```cmd
   cd C:\BP-DragonFly-Garden
   ```

3. **Download the latest code**
   - On Pi:
   ```bash
   git pull
   ```
   - On Laptop:
   ```cmd
   git pull
   ```

4. **Install backend dependencies**
   - On Pi:
   ```bash
   cd restaurant-system/backend
   npm install
   ```
   - On Laptop:
   ```cmd
   cd restaurant-system\backend
   npm install
   ```

5. **Build the frontend**
   - On Pi:
   ```bash
   cd /home/pi/BP-DragonFly-Garden/frontend
   npm install
   npm run build
   ```
   - On Laptop:
   ```cmd
   cd C:\BP-DragonFly-Garden\frontend
   npm install
   npm run build
   ```

6. **Restart the system**
   - On Pi:
   ```bash
   sudo systemctl restart dragonfly-garden
   ```
   - On Laptop:
   - Close Command Prompt
   - Open new Command Prompt
   - Type:
   ```cmd
   cd C:\BP-DragonFly-Garden\restaurant-system\backend
   npm run start
   ```

## ❓ TROUBLESHOOTING

### Problem: "git: command not found"
**Solution:**
- Git is not installed
- Install Git:
  - On Pi: `sudo apt install git -y`
  - On Laptop: Download from git-scm.com

### Problem: "npm: command not found"
**Solution:**
- Node.js is not installed
- Install Node.js from nodejs.org

### Problem: "npm install" fails
**Solution:**
1. Check your internet connection
2. Try again
3. If still fails, check the error message

### Problem: "npm run build" fails
**Solution:**
1. Check you have enough disk space
2. Try: `npm install` again
3. If still fails, check the error message
