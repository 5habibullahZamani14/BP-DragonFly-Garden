# 06.3 - CHECK THE CODE VERSION

This compares Git commits; it does not check the database, printer, or whether the app is
healthy.

## In the manager dashboard

Open **Settings → System → Check for Updates**. The result is a remote code-version
comparison. Do not use the adjacent **Update Now** button on a production machine; see
[06.1-GITHUB_UPDATES.md](06.1-GITHUB_UPDATES.md).

## In a terminal

From the project root:

```text
git status --short
git branch --show-current
git rev-parse --short HEAD
git fetch origin
git rev-parse --short origin/main
```

The final command only compares correctly if `main` is the intended deployment branch.
If the machine deploys another branch, compare its corresponding `origin/<branch>`.
Different commit IDs mean the checked-out code and remote reference differ; that does not
by itself prove that the remote commit is newer or safe to deploy.

Before updating, confirm the worktree is clean, the branch and remote are correct, and a
backup exists. Follow [06.1-GITHUB_UPDATES.md](06.1-GITHUB_UPDATES.md). Never use a hard
reset to force the versions to match.
