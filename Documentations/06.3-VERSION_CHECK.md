# 06.3 - VERSION CHECK

> **This guide is for COMPLETE BEGINNERS. We will explain EVERYTHING step by step. This shows you how to check the system version.**

---

## 🤔 WHY CHECK VERSION?

You check the version to:
- See if an update is available
- Know what features you have
- Know if you have the latest fixes

---

## 🔍 METHOD 1: CHECK FROM MANAGER DASHBOARD

### What to do:
1. **Open the restaurant system**
   - On Pi: `http://10.42.0.1:5000`
   - On Laptop: `http://localhost:5000`

2. **Login as manager**
   - Click "Manager Login"
   - Enter username and password

3. **Go to Settings → System**
   - Click "Settings" in the menu
   - Click "System"

4. **Click "Check for Updates"**
   - The system will check GitHub
   - You'll see:
     - "Current version: abc123"
     - "Latest version: def456"
     - "Up to date: Yes/No"

---

## 💻 METHOD 2: CHECK FROM COMMAND LINE

### What to do:
1. **Open Terminal**
   - On Pi: Click the black square icon
   - On Laptop: Open Command Prompt

2. **Go to the project folder**
   - On Pi:
   ```bash
   cd /home/pi/BP-DragonFly-Garden
   ```
   - On Laptop:
   ```cmd
   cd C:\BP-DragonFly-Garden
   ```

3. **Check current version**
   - On Pi:
   ```bash
   git rev-parse HEAD
   ```
   - On Laptop:
   ```cmd
   git rev-parse HEAD
   ```
   - You'll see a long code like: `abc123def456`

4. **Check latest version**
   - On Pi:
   ```bash
   git fetch origin
   git rev-parse origin/main
   ```
   - On Laptop:
   ```cmd
   git fetch origin
   git rev-parse origin/main
   ```

---

## 📊 WHAT THE VERSION NUMBERS MEAN

### Example:
- **Current version:** `abc123`
- **Latest version:** `def456`

### If they're the same:
- ✅ You have the latest version
- No update needed

### If they're different:
- ⚠️ Update is available
- Click "Update Now" in dashboard
- Or follow update guide

---

## 🔄 HOW TO UPDATE

### If update is available:
1. **From dashboard**
   - Click "Update Now"
   - Wait for update

2. **From command line**
   ```bash
   git pull
   npm install
   npm run build
   ```

---

## ❓ TROUBLESHOOTING

### Problem: "git: command not found"
**Solution:**
- Git is not installed
- Install Git or use dashboard method

### Problem: "fatal: not a git repository"
**Solution:**
- The system wasn't installed with Git
- Use the dashboard method instead

### Problem: Can't connect to GitHub
**Solution:**
- Check your internet connection
- Try again later
- Or use manual update
