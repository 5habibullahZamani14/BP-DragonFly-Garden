# 03.1 - SOFTWARE INSTALLATION (WINDOWS LAPTOP)

> **This guide is for COMPLETE BEGINNERS. We will explain EVERYTHING step by step. This installs Node.js and Git on your Windows laptop.**

---

## 🤔 WHAT IS NODE.JS?

Node.js is a program that lets your laptop run the restaurant system.

- **Think of it like:** Java or .NET Framework
- **Without it:** The system won't work
- **We need version 18 or newer**

---

## 🤔 WHAT IS GIT?

Git is a program that downloads the restaurant system from the internet.

- **Think of it like:** Downloading a ZIP file, but smarter
- **Without it:** You can't update the system easily

---

## 📥 STEP 1: DOWNLOAD NODE.JS

### What to do:
1. **Open Chrome or Edge browser**
   - Click the Start button (Windows logo)
   - Type "Chrome" or "Edge"
   - Click on the browser

2. **Go to the Node.js website**
   - In the address bar at the top, type:
   ```
   https://nodejs.org
   ```
   - Press Enter

3. **Download Node.js**
   - Look for a big button
   - It says "LTS" (Long Term Support)
   - Click it
   - The file will download

---

## 🔧 STEP 2: INSTALL NODE.JS

### What to do:
1. **Find the downloaded file**
   - Open File Explorer (folder icon on taskbar)
   - Click "Downloads" on the left
   - Look for `node-v18.x.x-x64.msi` (or similar)

2. **Double-click the file**
   - This starts the installation
   - A window will open

3. **Click "Next"**
   - Click the "Next" button
   - Read the license if you want
   - Click "Next"

4. **Click "Install"**
   - Click the "Install" button
   - Wait for it to finish
   - You may see a progress bar

5. **Click "Finish"**
   - When done, click "Finish"
   - The window will close

---

## 📥 STEP 3: DOWNLOAD GIT

### What to do:
1. **In your browser, go to:**
   ```
   https://git-scm.com/download/win
   ```
   - Press Enter

2. **The download will start automatically**
   - Look for a file like `Git-2.40.x-64-bit.exe`

3. **Find the downloaded file**
   - In File Explorer → Downloads
   - Look for the Git file

4. **Double-click the file**
   - This starts the installation

5. **Click "Next"**
   - Click through all the screens
   - Use default settings
   - Click "Next" until you see "Install"

6. **Click "Install"**
   - Wait for it to finish

7. **Click "Finish"**
   - When done, click "Finish"

---

## ✅ STEP 4: VERIFY INSTALLATION

### What to do:
1. **Open Command Prompt**
   - Click Start button
   - Type "cmd"
   - Click "Command Prompt"

2. **Check Node.js**
   - Type this command:
   ```
   node --version
   ```
   - Press Enter
   - You should see something like: `v18.17.0`
   - If you see an error, Node.js didn't install correctly

3. **Check npm**
   - Type this command:
   ```
   npm --version
   ```
   - Press Enter
   - You should see a number like: `9.6.7`

4. **Check Git**
   - Type this command:
   ```
   git --version
   ```
   - Press Enter
   - You should see something like: `git version 2.40.1`

---

## 📂 STEP 5: GET THE RESTAURANT SYSTEM FILES

### What to do:
1. **Decide how to get the files**
   - **Option A:** Copy from Pi (USB drive)
   - **Option B:** Download from GitHub
   - **Option C:** Copy from backup

2. **If copying from Pi:**
   - Copy the entire `BP-DragonFly-Garden` folder
   - Paste it in `C:\` on your laptop
   - You should see: `C:\BP-DragonFly-Garden\`

3. **If downloading from GitHub:**
   - Open Command Prompt
   - Type:
   ```
   cd C:\
   git clone https://github.com/YOUR_USERNAME/BP-DragonFly-Garden.git
   ```
   - Replace `YOUR_USERNAME` with the actual username
   - Wait for download

---

## 📥 STEP 6: INSTALL DEPENDENCIES

### What to do:
1. **Open Command Prompt**

2. **Go to the backend folder:**
   ```
   cd C:\BP-DragonFly-Garden\restaurant-system\backend
   ```
   - Press Enter

3. **Install backend dependencies:**
   ```
   npm install
   ```
   - Press Enter
   - Wait 2-3 minutes
   - This downloads all needed files

4. **Go to frontend folder:**
   ```
   cd C:\BP-DragonFly-Garden\frontend
   ```
   - Press Enter

5. **Install frontend dependencies:**
   ```
   npm install
   ```
   - Press Enter
   - Wait 2-3 minutes

## ❓ TROUBLESHOOTING

### Problem: "node is not recognized"
**Solution:**
- Node.js didn't install correctly
- Try installing again
- Make sure to use the LTS version

### Problem: "npm is not recognized"
**Solution:**
- Same as above - reinstall Node.js

### Problem: "git is not recognized"
**Solution:**
- Git didn't install correctly
- Try installing again
- Or download from GitHub website instead

### Problem: "npm install" takes forever
**Solution:**
- This is normal - it downloads many files
- Wait 5-10 minutes
- If it fails, check your internet connection
