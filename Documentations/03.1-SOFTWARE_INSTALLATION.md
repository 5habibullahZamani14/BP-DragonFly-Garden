# 03.1 - SOFTWARE INSTALLATION (WINDOWS)

The Windows deployment launcher requires Node.js 20 or newer. Install Git to clone and
update the project.

## Install Node.js

1. Download the current Node.js LTS installer from [nodejs.org](https://nodejs.org/).
2. Run the installer using its default options.
3. Close and reopen Command Prompt, then verify:

   ```text
   node --version
   npm --version
   ```

   `node --version` must report v20 or newer.

## Install Git

1. Download Git for Windows from [git-scm.com](https://git-scm.com/download/win).
2. Install with the defaults.
3. Open a new Command Prompt and verify with `git --version`.

## Get the source code

In Command Prompt:

```text
cd /d C:\
git clone https://github.com/5habibullahZamani14/BP-DragonFly-Garden.git
```

If GitHub requires authentication, use an authorized method. Never put a token or
password in the clone URL. For an offline setup, use a complete trusted source release;
do not copy another machine's `node_modules`, live SQLite database, or `.env` as source
code.

## Install dependencies

From the project directory:

```text
cd /d C:\BP-DragonFly-Garden\restaurant-system\backend
npm ci
cd /d C:\BP-DragonFly-Garden\frontend
npm ci
```

`npm ci` installs the versions recorded in the lockfiles. If it reports that a lockfile is
missing or inconsistent, stop and obtain the complete project release instead of
substituting `npm install`.

Next, create a machine-specific configuration using
[03.3-ENVIRONMENT_CONFIG.md](03.3-ENVIRONMENT_CONFIG.md), then start the app with the
Windows launcher described in [03-LAPTOP_SETUP_GUIDE.md](03-LAPTOP_SETUP_GUIDE.md).
