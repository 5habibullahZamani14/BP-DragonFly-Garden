# 05.1 - BACKUP PROCEDURES

> **This guide is for COMPLETE BEGINNERS. We will explain EVERYTHING step by step. This shows you how to create backups.**

---

## 🤔 WHAT IS A BACKUP?

A backup is a COPY of your important files. If something breaks, you can RESTORE from the backup.

### Think of it like:
- Taking a photo of your setup
- Writing down all your passwords
- Saving your data in a safe place

---

## 🔄 TWO TYPES OF BACKUPS

### Type 1: Automatic Cloud Backup
- **When:** Every day at 3:00 AM
- **Where:** Backblaze B2 cloud storage
- **What:** Database, images, environment files
- **You don't need to do anything!**

### Type 2: Manual Backup
- **When:** Whenever you want
- **Where:** Your USB drive or laptop
- **What:** Everything you need to restore
- **You do this yourself**

---

## ☁️ AUTOMATIC CLOUD BACKUP

### What happens automatically:
1. Every day at 3:00 AM
2. The system creates a backup
3. It encrypts the backup
4. It uploads to Backblaze B2
5. You can restore from it anytime

### To check if it's working:
1. **Login to manager dashboard**
2. **Go to Settings → System**
3. **Look for "Last backup" date**
4. **If it shows today's date, it's working!**

---

## 💾 MANUAL BACKUP (DO IT YOURSELF)

### What to back up:

| File/Folder | Why it's important |
|-------------|------------------|
| `.env` | Contains passwords and settings |
| `database.sqlite` | Contains all your data (orders, menu, employees) |
| `menu-images/` | Contains your menu pictures |
| `feedback-images/` | Contains feedback pictures |
| `dragonfly-garden.service` | Makes system auto-start on Pi |

---

## 📥 STEP 1: CREATE BACKUP FOLDER

### On the Pi:
1. **Open Terminal**
   - Click the black square icon
   - Or right-click desktop → Accessories → Terminal

2. **Type this command:**
   ```bash
   mkdir -p /home/pi/backup
   ```
   - Press Enter
   - This creates a backup folder

---

## 📥 STEP 2: COPY THE .env FILE

### What to do:
1. **Type this command:**
   ```bash
   cp /home/pi/BP-DragonFly-Garden/restaurant-system/backend/.env /home/pi/backup/
   ```
   - Press Enter
   - This copies the .env file

2. **Verify it copied:**
   ```bash
   ls -la /home/pi/backup/.env
   ```
   - You should see the file listed

---

## 📥 STEP 3: COPY THE DATABASE

### What to do:
1. **Type this command:**
   ```bash
   cp /home/pi/BP-DragonFly-Garden/restaurant-system/backend/src/database/database.sqlite /home/pi/backup/
   ```
   - Press Enter
   - This copies the database

2. **Verify it copied:**
   ```bash
   ls -la /home/pi/backup/database.sqlite
   ```
   - You should see the file listed

---

## 📥 STEP 4: COPY THE IMAGES

### What to do:
1. **Type this command:**
   ```bash
   cp -r /home/pi/BP-DragonFly-Garden/frontend/public/menu-images /home/pi/backup/
   ```
   - Press Enter
   - This copies menu images

2. **Type this command:**
   ```bash
   cp -r /home/pi/BP-DragonFly-Garden/frontend/public/feedback-images /home/pi/backup/
   ```
   - Press Enter
   - This copies feedback images

---

## 📥 STEP 5: COPY THE SERVICE FILE

### What to do:
1. **Type this command:**
   ```bash
   cp /etc/systemd/system/dragonfly-garden.service /home/pi/backup/
   ```
   - Press Enter
   - This copies the auto-start configuration

---

## 📦 STEP 6: CREATE A ZIP FILE

### What to do:
1. **Type this command:**
   ```bash
   cd /home/pi/backup
   ```
   - Press Enter

2. **Type this command:**
   ```bash
   tar -czf dragonfly-backup-$(date +%Y%m%d).tar.gz .
   ```
   - Press Enter
   - This creates a ZIP file with today's date

3. **Check the file:**
   ```bash
   ls -la dragonfly-backup-*.tar.gz
   ```
   - You should see the backup file

---

## 💿 STEP 7: COPY TO USB DRIVE

### What to do:
1. **Insert USB drive into Pi**
   - It will appear on the desktop

2. **Copy the backup file**
   - Drag the `.tar.gz` file to the USB drive
   - Or use the file manager

3. **Safely eject**
   - Right-click the USB drive
   - Click "Eject" or "Unmount"
