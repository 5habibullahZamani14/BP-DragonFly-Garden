# 02.3 - PRINTER SETUP GUIDE (YHD-8390)

> **This guide is for COMPLETE BEGINNERS. We will explain EVERYTHING step by step. This sets up the YHD-8390 thermal printer.**

---

## 🤔 WHAT IS CUPS?

CUPS is the printing system for Linux. It lets the Pi talk to the printer.

- **CUPS = Common Unix Printing System**
- It manages all printers
- It's like "Devices and Printers" in Windows

---

## 🔌 STEP 1: CONNECT THE PRINTER

### What to do:
1. **Find the USB cable**
   - It came with the YHD-8390 printer
   - One end is USB-A (normal USB)
   - One end is USB-B (square USB, goes into printer)

2. **Plug the USB cable**
   - USB-B end → into the printer
   - USB-A end → into the Pi
   - Turn on the printer
   - The power light should be on

---

## 💻 STEP 2: OPEN THE TERMINAL

### What to do:
1. **Click the black square icon**
   - On the top left of the screen
   - Says "Terminal" when you hover over it

2. **Or right-click on the desktop**
   - Click "Accessories"
   - Click "Terminal"

---

## 📥 STEP 3: INSTALL CUPS

### What to do:
1. **Type this command exactly:**
   ```bash
   sudo apt update
   ```
   - Press Enter
   - Wait for it to finish

2. **Type this command:**
   ```bash
   sudo apt install cups cups-client -y
   ```
   - Press Enter
   - Wait 2-3 minutes
   - This installs CUPS

3. **Add your user to the printer group**
   ```bash
   sudo usermod -a -G lpadmin pi
   ```
   - Press Enter
   - This lets you manage printers

4. **Restart the Pi**
   ```bash
   sudo reboot
   ```
   - Press Enter
   - Wait for restart

---

## 🌐 STEP 4: OPEN CUPS WEB INTERFACE

### What to do:
1. **Login to the Pi again**

2. **Open the Chromium browser**
   - Click the blue globe icon
   - Or click Start → type "Chromium"

3. **Type in the address bar:**
   ```
   http://localhost:631
   ```
   - Press Enter
   - This opens CUPS

---

## ➕ STEP 5: ADD THE PRINTER

### What to do:
1. **Click "Administration" tab**
   - At the top of the page

2. **Click "Add Printer"**
   - You may need to login
   - Username: `pi`
   - Password: (your password)

3. **Select the printer**
   - Look for "USB Serial Port" or "YHD-8390"
   - Click on it
   - Click "Continue"

4. **Name the printer**
   - Name: `YHD-8390`
   - Description: `80mm Thermal Printer with Auto Cutter`
   - Click "Continue"

5. **Select the driver**
   - Click "Select Another Make/Manufacturer"
   - Click "Raw"
   - Click "Add Printer"

6. **Set paper size**
   - Click "Set Default Options"
   - This saves the printer

---

## ✅ STEP 6: TEST THE PRINTER

### What to do:
1. **In CUPS, click "Printers" tab**
   - You should see "YHD-8390"

2. **Click on "YHD-8390"**
   - Click "Print Test Page"
   - The printer should print

3. **If it doesn't work**
   - Check the USB cable
   - Check if printer is turned on
   - Try a different USB port

---

## ⚙️ STEP 7: CONFIGURE IN THE RESTAURANT SYSTEM

### What to do:
1. **Open the restaurant system**
   - In browser, go to: `http://10.42.0.1:5000`

2. **Login as manager**
   - Click "Manager Login"
   - Enter username and password

3. **Go to Settings → Printer Management**
   - Click "Settings" in the menu
   - Click "Printer Management"

4. **Click "Discover Printers"**
   - The system will find your printer

5. **Select the printer**
   - Click on "YHD-8390" in the dropdown

6. **Set printer settings**
   - **Width:** `48` (for 80mm paper)
   - **Print Delay:** `0` (for auto-cutter)
   - **Empty Lines Before:** `2`
   - **Empty Lines After:** `3`
   - **Has Auto Cutter:** `Yes` (check the box)

7. **Click "Save Printer Settings"**
   - This saves the configuration

8. **Click "Test Print"**
   - The printer should print a test ticket
   - It should use full width
   - It should cut the paper automatically

---

## ❓ TROUBLESHOOTING

### Problem: Printer not found in CUPS
**Solution:**
1. Check the USB cable connection
2. Check if printer is turned on
3. Try a different USB port
4. Run: `lsusb` in terminal to see if Pi detects the printer

### Problem: Test page prints but with wrong width
**Solution:**
1. In the restaurant system, set Width to 48
2. Make sure "Has Auto Cutter" is checked
3. Click "Save Printer Settings"

### Problem: Paper doesn't cut automatically
**Solution:**
1. In the restaurant system, set "Print Delay" to 0
2. Make sure "Has Auto Cutter" is checked
3. The system sends the cut command automatically

### Problem: Printer prints garbage
**Solution:**
1. Make sure you selected "Raw" driver in CUPS
2. Do NOT use the POS-80C driver
3. Delete the printer and re-add with "Raw" driver
