# 02.1 - OS INSTALLATION GUIDE

> **This guide is for COMPLETE BEGINNERS. We will explain EVERYTHING step by step.**

---

## 🤔 WHAT IS AN OPERATING SYSTEM (OS)?

Think of the OS like the brain of the Pi. Without it, the Pi is just a piece of plastic and metal. The OS lets the Pi:
- Run programs
- Connect to WiFi
- Save files
- Do everything a computer does

We will install "Raspberry Pi OS" which is made for the Pi.

---

## 📥 STEP 1: DOWNLOAD RASPBERRY PI IMAGER

### What to do:
1. **Open your laptop**
   - Turn it on
   - Login if needed

2. **Open a web browser**
   - Click the Start button (Windows logo in bottom left)
   - Type "Chrome" or "Edge"
   - Click on the browser

3. **Go to the download page**
   - In the address bar at the top, type:
   ```
   https://www.raspberrypi.com/software/
   ```
   - Press Enter

4. **Download the imager**
   - Look for a big blue button
   - It says "Download for Windows"
   - Click it
   - A box may appear asking "What do you want to do with this file?"
   - Click "Save" or "Download"
   - Wait for the download to finish

---

## 📂 STEP 2: FIND THE DOWNLOADED FILE

### What to do:
1. **Open File Explorer**
   - Click the folder icon on the taskbar
   - Or click Start → type "File Explorer" → click it

2. **Go to Downloads**
   - On the left side, click "Downloads"
   - Look for a file named something like:
     - `imager_1.8.5.exe` (the number may be different)
     - Or `imager.exe`

3. **If you can't find it**
   - Click "This PC" on the left
   - Click "Downloads" under "Quick access"
   - Or search for "imager" in the search box at the top right

---

## 🔧 STEP 3: INSTALL RASPBERRY PI IMAGER

### What to do:
1. **Double-click the downloaded file**
   - This starts the installation
   - A window will open

2. **Click "Next"**
   - Click the "Next" button
   - Read the license if you want (or skip it)
   - Click "Next" again

3. **Choose where to install**
   - Leave the default location
   - Click "Next"

4. **Click "Install"**
   - Click the "Install" button
   - Wait for it to finish
   - You may see a progress bar

5. **Click "Finish"**
   - When done, click "Finish"
   - The window will close

---

## 💾 STEP 4: PUT SD CARD IN YOUR LAPTOP

### What to do:
1. **Get your SD card**
   - Take the micro SD card (32GB or larger)
   - If it's in an adapter, that's fine

2. **Find the SD card slot on your laptop**
   - It's usually on the side
   - It's about the size of a coin
   - If your laptop doesn't have one, use a USB SD card reader

3. **Insert the SD card**
   - Put it in gently
   - You'll feel it click into place
   - Don't force it!

---

## 🖥️ STEP 5: OPEN RASPBERRY PI IMAGER

### What to do:
1. **Click the Start button**
   - Bottom left corner of screen
   - Windows logo

2. **Type "Raspberry Pi Imager"**
   - Click the search box
   - Type these words exactly

3. **Click on "Raspberry Pi Imager"**
   - It will appear in the search results
   - Click on it
   - Wait for the program to open

---

## ⚙️ STEP 6: CHOOSE THE OPERATING SYSTEM

### What to do:
1. **Click "Choose OS"**
   - Big button in the middle
   - Says "Choose OS"

2. **Click "Raspberry Pi OS (other)"**
   - Scroll down if needed
   - Click on this option

3. **Click "Raspberry Pi OS (64-bit)"**
   - ⚠️ **IMPORTANT**: Choose 64-bit, NOT 32-bit
   - This is important for the restaurant system

---

## 💾 STEP 7: CHOOSE THE SD CARD

### What to do:
1. **Click "Choose Storage"**
   - Big button next to "Choose OS"

2. **Click on your SD card**
   - Look at the size
   - Make sure it matches your SD card (32GB, 64GB, etc.)
   - Click on it

3. **⚠️ WARNING**
   - Make sure you select the RIGHT SD card
   - Everything on it will be deleted!
   - If you're not sure, check the size

---

## ✍️ STEP 8: (OPTIONAL) SETUP BEFORE WRITING

### What to do:
1. **Click the gear icon (⚙️)**
   - Next to the "Write" button
   - This opens advanced settings

2. **Set hostname**
   - In "Set hostname", type:
   ```
   dragonfly-pi
   ```

3. **Set username and password**
   - Username: `pi`
   - Password: (choose a password you'll remember)
   - ⚠️ Write this down! You'll need it later

4. **Configure WiFi**
   - Skip this for now
   - We'll set up the hotspot later

5. **Click "Save"**
   - Click the "Save" button
   - This closes the settings

---

## 🔨 STEP 9: WRITE THE OS TO THE SD CARD

### What to do:
1. **Click "Write"**
   - Big button
   - Says "Write"

2. **Click "Yes"**
   - If Windows asks for permission
   - Click "Yes"

3. **Wait 5-10 minutes**
   - You'll see a progress bar
   - The SD card is being written
   - ⚠️ DO NOT remove the SD card!
   - ⚠️ DO NOT close the program!

4. **When done**
   - A box will appear
   - Click "Continue"

---

## 📤 STEP 10: EJECT THE SD CARD

### What to do:
1. **Go back to File Explorer**
   - Click the folder icon on taskbar

2. **Find the SD card**
   - Look under "This PC"
   - It might say "removable disk"

3. **Right-click the SD card**
   - Click "Eject"
   - Wait for the message "Safe to Remove Hardware"

4. **Remove the SD card**
   - Gently pull it out
   - Don't force it!

---

## ❓ TROUBLESHOOTING

| Problem | Solution |
|--------|----------|
| Can't find the downloaded file | Check "Downloads" folder, search for "imager" |
| SD card not showing in imager | Try a different SD card reader, check if SD card is inserted |
| Write failed | Try a different SD card, check if it's locked (little switch on side) |
| Forgot the password I set | You'll need to redo the process, write it down this time |
