# 02.1 - RASPBERRY PI OS INSTALLATION

This guide prepares an SD card with Raspberry Pi OS using Raspberry Pi Imager. Imager's
screens and OS names can change; choose the current 64-bit Raspberry Pi OS image
compatible with the Pi model.

## Write the operating system

1. Download and install Raspberry Pi Imager from
   [raspberrypi.com/software](https://www.raspberrypi.com/software/).
2. Insert the intended microSD card into the computer. Writing the image erases the card;
   verify the selected storage device carefully.
3. In Imager, choose the Pi model, current 64-bit Raspberry Pi OS, and the correct SD
   card.
4. Configure a hostname and create a unique Linux user/password if Imager offers OS
   customization. Current OS releases do not necessarily create a `pi` user. Save the
   credentials securely because the systemd guide needs the actual account name.
5. Configure a temporary setup network or SSH only if required. The restaurant hotspot
   is configured later; these are separate network settings.
6. Write and verify the image, then safely eject the card.

## First boot

1. Insert the SD card into the Pi and connect a display/keyboard or use the configured
   remote access method.
2. Connect power and wait for the OS first-boot setup to finish.
3. Sign in with the Linux account created during imaging.
4. Connect to the internet temporarily if needed to install OS packages and application
   dependencies.
5. Continue with [02-PI_SETUP_GUIDE.md](02-PI_SETUP_GUIDE.md).

**Important:** Selecting a 32 GB card, hostname, username, or exact Imager menu label in an
older screenshot is not a requirement of the app. Choose storage appropriate for the
deployment and keep verified backups on a separate device.
