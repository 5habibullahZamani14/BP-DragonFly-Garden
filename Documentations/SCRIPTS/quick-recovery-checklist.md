# Quick recovery checklist

The current recovery checklist is
[05.4-QUICK_RECOVERY.md](../05.4-QUICK_RECOVERY.md). This older copy is intentionally
replaced because it contained unsupported claims that a spare SD card would boot
automatically, that the printer model/width was fixed, and that the legacy cloud restore
script was safe.

Use one active server at a time and verify the database, login, and physical printer
before resuming service.
