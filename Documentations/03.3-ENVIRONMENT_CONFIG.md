# 03.3 - ENVIRONMENT CONFIGURATION (WINDOWS LAPTOP)

> **This guide is for COMPLETE BEGINNERS. We will explain EVERYTHING step by step. This copies the .env file to your laptop.**

---

## 🤔 WHAT IS THE .env FILE?

The `.env` file is like a settings file. It contains:

- **Passwords** (JWT_SECRET, API keys)
- **IP addresses** (where the system runs)
- **Database settings** (where data is stored)
- **Printer settings** (how to print)

### ⚠️ WITHOUT THIS FILE, THE SYSTEM WON'T WORK!

---

## 📥 STEP 1: GET THE .env FILE

### What to do:
1. **Get the .env file from the Pi**
   - Use a USB drive
   - Or email it to yourself
   - Or copy from backup

2. **The file is at:**
   ```
   /home/pi/BP-DragonFly-Garden/restaurant-system/backend/.env
   ```

3. **Copy it to your laptop:**
   ```
   C:\BP-DragonFly-Garden\restaurant-system\backend\.env
   ```

---

## 🔧 STEP 2: WHAT'S IN THE .env FILE

### Here's what each setting means:

| Setting | What it does | Example value |
|---------|-------------|--------------|
| `PORT` | The port number the system runs on | `5000` |
| `HOST` | The IP address to listen on | `0.0.0.0` (all interfaces) |
| `JWT_SECRET` | Secret key for login (KEEP PRIVATE!) | `YOUR_JWT_SECRET_HERE` |
| `RESEND_API_KEY` | Email service key | `YOUR_RESEND_API_KEY_HERE` |
| `B2_KEY_ID` | Backblaze cloud storage key | `YOUR_B2_KEY_ID_HERE` |
| `B2_APPLICATION_KEY` | Backblaze application key | `YOUR_B2_APPLICATION_KEY_HERE` |
| `B2_ENDPOINT` | Backblaze server address | `s3.us-east-005.backblazeb2.com` |
| `B2_BUCKET_NAME` | Backblaze bucket name | `YOUR_B2_BUCKET_NAME_HERE` |
| `BACKUP_ENC_KEY` | Encryption key for backups | `YOUR_BACKUP_ENC_KEY_HERE` |
| `CORS_ALLOWED_ORIGINS` | Allowed websites | `http://localhost:5173,http://10.42.0.1:5000` |
| `CAPTIVE_PORTAL_TARGET` | Where to redirect users | `http://10.42.0.1:5000/` |

---

## ✏️ STEP 3: EDIT THE .env FILE

### What to do:
1. **Right-click the .env file**
   - In File Explorer
   - Click "Open with"
   - Click "Notepad"

2. **⚠️ DO NOT CHANGE THESE VALUES:**
   - `JWT_SECRET`
   - `RESEND_API_KEY`
   - `B2_KEY_ID`
   - `B2_APPLICATION_KEY`
   - `B2_ENDPOINT`
   - `B2_BUCKET_NAME`
   - `BACKUP_ENC_KEY`

3. **You CAN change these (if you know what you're doing):**
   - `PORT` (only if you want a different port)
   - `HOST` (leave as `0.0.0.0`)
   - `CORS_ALLOWED_ORIGINS` (add your laptop's IP if needed)

4. **Save the file**
   - Press `Ctrl + S`
   - Click "Save"

---

## 🔍 STEP 4: VERIFY THE .env FILE

### What to do:
1. **Open Command Prompt**
   - Click Start
   - Type "cmd"
   - Click "Command Prompt"

2. **Go to the backend folder:**
   ```
   cd C:\BP-DragonFly-Garden\restaurant-system\backend
   ```

3. **Check if .env exists:**
   ```
   dir .env
   ```
   - You should see: `01/01/2024  01:00 PM             1,234 .env`

4. **If you see "File Not Found"**
   - The .env file is missing
   - Copy it from the Pi again

---

## ▶️ STEP 5: START THE SYSTEM

### What to do:
1. **Open Command Prompt**

2. **Go to the backend folder:**
   ```
   cd C:\BP-DragonFly-Garden\restaurant-system\backend
   ```

3. **Start the system:**
   ```
   npm run start
   ```
   - Press Enter
   - Wait for: `Server running on http://0.0.0.0:5000`

4. **If you see an error about JWT_SECRET**
   - The .env file is missing or wrong
   - Check Step 4

5. **If you see "Error: listen EADDRINUSE"**
   - Something else is using port 5000
   - Close other programs or change the PORT in .env

---

## 🌐 STEP 6: TEST THE SYSTEM

### What to do:
1. **Open a browser**
   - Chrome, Edge, or Firefox

2. **Type in the address bar:**
   ```
   http://localhost:5000
   ```
   - Press Enter

3. **You should see the restaurant system!**
   - If you see it, the .env is correct
   - If not, check the error message

## ❓ TROUBLESHOOTING

### Problem: "JWT_SECRET is not set"
**Solution:**
1. Check if .env file exists:
   ```
   dir C:\BP-DragonFly-Garden\restaurant-system\backend\.env
   ```
2. If it doesn't exist, copy it from the Pi
3. If it exists, make sure it has `JWT_SECRET=...`

### Problem: "RESEND_API_KEY not set"
**Solution:**
- This is optional (for password reset emails)
- The system will still work without it
- But password reset won't work

### Problem: "B2_KEY_ID not set"
**Solution:**
- This is for cloud backups
- The system will still work
- But automatic backups won't work

### Problem: "Port 5000 is in use"
**Solution:**
1. Close other programs
2. Or change PORT in .env to `5001`
3. Then access at `http://localhost:5001`
