# 06.2 - MANUAL UPDATES

> **This guide is for COMPLETE BEGINNERS. We will explain EVERYTHING step by step. This shows you how to manually update the system.**

---

## 🤔 WHEN TO USE MANUAL UPDATES?

Use manual updates when:
- GitHub update doesn't work
- You downloaded a ZIP file
- You want to update from a USB drive
- The manager gave you files

---

## 💾 STEP 1: GET THE UPDATE FILES

### What to do:
1. **Get the files from the manager**
   - USB drive
   - Email attachment
   - Download from website

2. **The files should include:**
   - All files in `restaurant-system/backend/src/`
   - All files in `frontend/src/`
   - `package.json` files
   - Other code files

---

## 📂 STEP 2: STOP THE SYSTEM

### On Pi:
```bash
sudo systemctl stop dragonfly-garden
```

### On Laptop:
- Press `Ctrl + C` in Command Prompt
- The system will stop

---

## 📋 STEP 3: REPLACE THE FILES

### What to do:
1. **Copy the new files**
   - Copy to the same locations
   - Overwrite the old files
   - ⚠️ DO NOT overwrite `.env` file!
   - ⚠️ DO NOT overwrite `database.sqlite`!

2. **Files to NOT overwrite:**
   - `.env` (your settings)
   - `database.sqlite` (your data)
   - `menu-images/` (your images)
   - `feedback-images/` (your images)

---

## 📥 STEP 4: INSTALL DEPENDENCIES

### What to do:
1. **Open Terminal/Command Prompt**

2. **Go to backend folder**
   - On Pi:
   ```bash
   cd /home/pi/BP-DragonFly-Garden/restaurant-system/backend
   ```
   - On Laptop:
   ```cmd
   cd C:\BP-DragonFly-Garden\restaurant-system\backend
   ```

3. **Install dependencies**
   ```bash
   npm install
   ```
   - Wait 2-3 minutes

---

## 🔨 STEP 5: BUILD THE FRONTEND

### What to do:
1. **Go to frontend folder**
   - On Pi:
   ```bash
   cd /home/pi/BP-DragonFly-Garden/frontend
   ```
   - On Laptop:
   ```cmd
   cd C:\BP-DragonFly-Garden\frontend
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```
   - Wait 2-3 minutes

3. **Build the frontend**
   ```bash
   npm run build
   ```
   - Wait 2-3 minutes
   - This creates the `dist/` folder

---

## ▶️ STEP 6: START THE SYSTEM

### On Pi:
```bash
sudo systemctl start dragonfly-garden
```

### On Laptop:
```cmd
cd C:\BP-DragonFly-Garden\restaurant-system\backend
npm run start
```

---

## ✅ STEP 7: TEST THE UPDATE

### What to do:
1. **Open the restaurant system**
   - On Pi: `http://10.42.0.1:5000`
   - On Laptop: `http://localhost:5000`

2. **Login and check**
   - Check your menu
   - Check your employees
   - Test the printer

3. **If something is wrong**
   - Restore from backup
   - Try again

---

## ❓ TROUBLESHOOTING

### Problem: "npm install" fails
**Solution:**
1. Check your internet connection
2. Check the files are correct
3. Try again

### Problem: "npm run build" fails
**Solution:**
1. Check you have enough disk space
2. Check Node.js version is 18+
3. Try: `npm install` again

### Problem: System won't start
**Solution:**
1. Check the .env file is there
2. Check the database is there
3. Check the logs for errors
