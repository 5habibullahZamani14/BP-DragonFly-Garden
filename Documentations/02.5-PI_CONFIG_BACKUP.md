# 02.5 - PI CONFIGURATION BACKUP

> **This guide is for COMPLETE BEGINNERS. We will explain EVERYTHING step by step. This shows you what to back up and how.**

---

## 🤔 WHAT IS A BACKUP?

A backup is a copy of important files. If something breaks, you can restore from the backup.

- **Think of it like:** Taking photos of your setup so you can remember it later
- **Why you need it:** If the SD card dies, you can restore everything
- **Where to store it:** USB drive, cloud storage, or laptop

---

## 📁 STEP 1: WHAT TO BACKUP

### These files are CRITICAL:

| File/Folder | Why it's important |
|-------------|------------------|
| `.env` | Contains passwords and settings |
| `database.sqlite` | Contains all your data (orders, menu, employees) |
| `menu-images/` | Contains your menu pictures |
| `feedback-images/` | Contains feedback pictures |
| `dragonfly-garden.service` | Makes system auto-start |

---

## 💾 STEP 2: CREATE A BACKUP FOLDER

### What to do:
1. **Open Terminal**
   - Click the black square icon
   - Or right-click desktop → Accessories → Terminal

2. **Type this command:**
   ```bash
   mkdir -p /home/pi/backup
   ```
   - Press Enter
   - This creates a backup folder

---

## 📥 STEP 3: COPY THE .env FILE

### What to do:
1. **Type this command:**
   ```bash
   cp /home/pi/BP-DragonFly-Garden/restaurant-system/backend/.env /home/pi/backup/
   ```
   - Press Enter
   - This copies the .env file

2. **Verify it copied:**
   ```bash
   ls -la /home/pi/backup/.env
   ```
   - You should see the file listed

---

## 📥 STEP 4: COPY THE DATABASE

### What to do:
1. **Type this command:**
   ```bash
   cp /home/pi/BP-DragonFly-Garden/restaurant-system/backend/src/database/database.sqlite /home/pi/backup/
   ```
   - Press Enter
   - This copies the database

2. **Verify it copied:**
   ```bash
   ls -la /home/pi/backup/database.sqlite
   ```
   - You should see the file listed

---

## 📥 STEP 5: COPY THE IMAGES

### What to do:
1. **Type this command:**
   ```bash
   cp -r /home/pi/BP-DragonFly-Garden/frontend/public/menu-images /home/pi/backup/
   ```
   - Press Enter
   - This copies menu images

2. **Type this command:**
   ```bash
   cp -r /home/pi/BP-DragonFly-Garden/frontend/public/feedback-images /home/pi/backup/
   ```
   - Press Enter
   - This copies feedback images

---

## 📥 STEP 6: COPY THE SERVICE FILE

### What to do:
1. **Type this command:**
   ```bash
   cp /etc/systemd/system/dragonfly-garden.service /home/pi/backup/
   ```
   - Press Enter
   - This copies the auto-start configuration

---

## 📦 STEP 7: CREATE A ZIP FILE

### What to do:
1. **Type this command:**
   ```bash
   cd /home/pi/backup
   ```
   - Press Enter

2. **Type this command:**
   ```bash
   tar -czf dragonfly-backup-$(date +%Y%m%d).tar.gz .
   ```
   - Press Enter
   - This creates a ZIP file with today's date

3. **Check the file:**
   ```bash
   ls -la dragonfly-backup-*.tar.gz
   ```
   - You should see the backup file

---

## 💿 STEP 8: COPY TO USB DRIVE

### What to do:
1. **Insert USB drive into Pi**
   - It will appear on the desktop

2. **Copy the backup file**
   - Drag the `.tar.gz` file to the USB drive
   - Or use the file manager

3. **Safely eject**
   - Right-click the USB drive
   - Click "Eject" or "Unmount"

---

## 🔄 STEP 9: RESTORE FROM BACKUP

### What to do:
1. **Insert the USB drive**

2. **Open Terminal**

3. **Type this command:**
   ```bash
   cd /home/pi
   ```
   - Press Enter

4. **Type this command:**
   ```bash
   tar -xzf /media/pi/USB_NAME/dragonfly-backup-DATE.tar.gz
   ```
   - Replace `USB_NAME` with your USB drive name
   - Replace `DATE` with the actual date
   - Press Enter

5. **Copy files back:**
   ```bash
   cp /home/pi/backup/.env /home/pi/BP-DragonFly-Garden/restaurant-system/backend/
   cp /home/pi/backup/database.sqlite /home/pi/BP-DragonFly-Garden/restaurant-system/backend/src/database/
   cp -r /home/pi/backup/menu-images /home/pi/BP-DragonFly-Garden/frontend/public/
   cp -r /home/pi/backup/feedback-images /home/pi/BP-DragonFly-Garden/frontend/public/
   sudo cp /home/pi/backup/dragonfly-garden.service /etc/systemd/system/
   ```

6. **Restart the system:**
   ```bash
   sudo systemctl daemon-reload
   sudo systemctl restart dragonfly-garden
   ```

---

## 📋 QUICK BACKUP COMMANDS

| Command | What it does |
|---------|-------------|
| `mkdir -p /home/pi/backup` | Create backup folder |
| `cp .env /home/pi/backup/` | Copy .env file |
| `cp database.sqlite /home/pi/backup/` | Copy database |
| `tar -czf backup.tar.gz /home/pi/backup/` | Create ZIP |
| `tar -xzf backup.tar.gz` | Extract ZIP |

## ❓ TROUBLESHOOTING

### Problem: "Permission denied" error
**Solution:**
- Add `sudo` before the command
- Example: `sudo cp .env /home/pi/backup/`

### Problem: "No such file" error
**Solution:**
- Check if the file exists:
  ```bash
  ls -la /home/pi/BP-DragonFly-Garden/restaurant-system/backend/.env
  ```
- If it doesn't exist, the system isn't installed yet

### Problem: USB drive not showing
**Solution:**
- Check if it's properly inserted
- Check the file manager
- Try a different USB port
