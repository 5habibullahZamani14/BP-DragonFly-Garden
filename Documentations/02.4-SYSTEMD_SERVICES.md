# 02.4 - SYSTEMD SERVICES (AUTO-START)

> **This guide is for COMPLETE BEGINNERS. We will explain EVERYTHING step by step. This makes the system start automatically when the Pi turns on.**

---

## 🤔 WHAT IS SYSTEMD?

Systemd is like the "Startup" folder in Windows. It makes programs start automatically when the Pi turns on.

- **Without systemd:** You have to manually start the system every time
- **With systemd:** The system starts automatically when the Pi turns on
- **It also restarts the system if it crashes**

---

## 📄 STEP 1: CREATE THE SERVICE FILE

### What to do:
1. **Open Terminal**
   - Click the black square icon
   - Or right-click desktop → Accessories → Terminal

2. **Type this command to create the file:**
   ```bash
   sudo nano /etc/systemd/system/dragonfly-garden.service
   ```
   - Press Enter
   - This opens a text editor

3. **Type EXACTLY this content:**
   ```
   [Unit]
   Description=Dragonfly Garden Backend
   After=network.target

   [Service]
   Type=simple
   User=pi
   WorkingDirectory=/home/pi/BP-DragonFly-Garden/restaurant-system/backend
   EnvironmentFile=/home/pi/BP-DragonFly-Garden/restaurant-system/backend/.env
   ExecStart=/usr/bin/node src/server.js
   Restart=on-failure
   RestartSec=5s
   LimitNOFILE=4096

   [Install]
   WantedBy=multi-user.target
   ```

4. **Save the file**
   - Press `Ctrl + O` (hold Ctrl, press O)
   - Press Enter
   - You'll see "Wrote 16 lines"

5. **Exit the editor**
   - Press `Ctrl + X`

---

## 🔧 STEP 2: ENABLE THE SERVICE

### What to do:
1. **Type this command:**
   ```bash
   sudo systemctl daemon-reload
   ```
   - Press Enter
   - This tells the Pi about the new service

2. **Type this command:**
   ```bash
   sudo systemctl enable dragonfly-garden.service
   ```
   - Press Enter
   - This makes it start on boot

3. **Type this command:**
   ```bash
   sudo systemctl start dragonfly-garden.service
   ```
   - Press Enter
   - This starts the system now

---

## ✅ STEP 3: CHECK IF IT'S WORKING

### What to do:
1. **Type this command:**
   ```bash
   sudo systemctl status dragonfly-garden.service
   ```
   - Press Enter

2. **Look for "active (running)"**
   - If you see this, it's working!
   - If you see "inactive", something is wrong

3. **If it's not working**
   - Check the error message
   - Make sure the .env file exists
   - Make sure you installed the system files

---

## 🔁 STEP 4: TEST AUTO-RESTART

### What to do:
1. **The system will automatically restart if it crashes**
   - This is the "Restart=on-failure" setting
   - It waits 5 seconds (RestartSec=5s)
   - Then starts again

2. **To test manually:**
   ```bash
   sudo systemctl restart dragonfly-garden.service
   ```
   - This restarts the system

---

## 📋 IMPORTANT COMMANDS

| Command | What it does |
|---------|-------------|
| `sudo systemctl start dragonfly-garden` | Start the system |
| `sudo systemctl stop dragonfly-garden` | Stop the system |
| `sudo systemctl restart dragonfly-garden` | Restart the system |
| `sudo systemctl status dragonfly-garden` | Check if running |
| `sudo journalctl -u dragonfly-garden -f` | See live logs |

## ❓ TROUBLESHOOTING

### Problem: Service won't start
**Solution:**
1. Check if .env file exists:
   ```bash
   ls -la /home/pi/BP-DragonFly-Garden/restaurant-system/backend/.env
   ```
2. If it doesn't exist, copy it from the backup
3. Check the logs:
   ```bash
   sudo journalctl -u dragonfly-garden -n 50
   ```

### Problem: "Unit not found" error
**Solution:**
1. Make sure you created the file in the right place:
   ```bash
   ls -la /etc/systemd/system/dragonfly-garden.service
   ```
2. If it doesn't exist, redo Step 1

### Problem: System starts but printer doesn't work
**Solution:**
1. Make sure CUPS is installed
2. Make sure the printer is connected
3. Check printer status:
   ```bash
   lpstat -p
   ```
