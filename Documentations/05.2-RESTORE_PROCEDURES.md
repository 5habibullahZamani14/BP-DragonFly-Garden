# 05.2 - RESTORE PROCEDURES

> **This guide is for COMPLETE BEGINNERS. We will explain EVERYTHING step by step. This shows you how to restore from backup.**

---

## 🤔 WHEN DO YOU NEED TO RESTORE?

### Scenarios:
1. **SD card died** - Need to restore to new SD card
2. **Data got corrupted** - Need to restore clean data
3. **Made a mistake** - Need to go back to previous state
4. **Want to set up new Pi** - Need to copy existing setup

---

## 🔄 THREE WAYS TO RESTORE

### Method 1: From Cloud Backup (Backblaze)
- **When:** SD card died, no local backup
- **Need:** Internet connection
- **Command:** `node src/restoreBackup.js`

### Method 2: From Local Backup File
- **When:** You have a backup ZIP file
- **Need:** USB drive with backup
- **Command:** Manual copy

### Method 3: From Uploaded Backup
- **When:** You downloaded a backup
- **Need:** Backup file on computer
- **Command:** Through manager dashboard

---

## ☁️ METHOD 1: RESTORE FROM CLOUD BACKUP

### What to do:
1. **On the Pi, open Terminal**
   - Click the black square icon
   - Or right-click desktop → Accessories → Terminal

2. **Type this command:**
   ```bash
   cd /home/pi/BP-DragonFly-Garden/restaurant-system/backend
   ```
   - Press Enter

3. **Type this command:**
   ```bash
   node src/restoreBackup.js
   ```
   - Press Enter
   - This restores from Backblaze

4. **Wait for the message:**
   - You'll see: "🎉 Restore complete! You can now restart your Node.js server."

5. **Restart the system:**
   ```bash
   sudo systemctl restart dragonfly-garden
   ```

---

## 💾 METHOD 2: RESTORE FROM LOCAL BACKUP

### What to do:
1. **Insert USB drive with backup**
   - The backup file should be named: `dragonfly-backup-DATE.tar.gz`

2. **Open Terminal**

3. **Type this command:**
   ```bash
   cd /home/pi
   ```
   - Press Enter

4. **Type this command (replace DATE):**
   ```bash
   tar -xzf /media/pi/USB_NAME/dragonfly-backup-DATE.tar.gz
   ```
   - Replace `USB_NAME` with your USB drive name
   - Replace `DATE` with the actual date
   - Press Enter

5. **Copy files back:**
   ```bash
   cp /home/pi/backup/.env /home/pi/BP-DragonFly-Garden/restaurant-system/backend/
   cp /home/pi/backup/database.sqlite /home/pi/BP-DragonFly-Garden/restaurant-system/backend/src/database/
   cp -r /home/pi/backup/menu-images /home/pi/BP-DragonFly-Garden/frontend/public/
   cp -r /home/pi/backup/feedback-images /home/pi/BP-DragonFly-Garden/frontend/public/
   sudo cp /home/pi/backup/dragonfly-garden.service /etc/systemd/system/
   ```

6. **Restart the system:**
   ```bash
   sudo systemctl daemon-reload
   sudo systemctl restart dragonfly-garden
   ```

## 🌐 METHOD 3: RESTORE FROM UPLOADED BACKUP

### What to do:
1. **Open the restaurant system**
   - Go to: `http://10.42.0.1:5000`

2. **Login as manager**
   - Click "Manager Login"
   - Enter username and password

3. **Go to Settings → Backup & Restore**
   - Click "Settings" in the menu
   - Click "Backup & Restore"

4. **Click "Choose File"**
   - Select your backup file
   - Click "Upload"

5. **Wait for restore to complete**
   - You'll see a success message

6. **Restart the system:**
   - The system will restart automatically
   - Or click "Restart" button

---

## ✅ STEP 3: VERIFY THE RESTORE

### What to do:
1. **Check the system is running:**
   ```bash
   sudo systemctl status dragonfly-garden
   ```
   - You should see "active (running)"

2. **Open the restaurant system:**
   - Go to: `http://10.42.0.1:5000`

3. **Login and check:**
   - Your menu should be there
   - Your employees should be there
   - Your settings should be there

4. **Test the printer:**
   - Go to Settings → Printer Management
   - Click "Test Print"
   - The printer should work

## ❓ TROUBLESHOOTING

### Problem: "Missing Backblaze credentials"
**Solution:**
1. Make sure .env file has:
   - `B2_KEY_ID`
   - `B2_APPLICATION_KEY`
   - `B2_ENDPOINT`
   - `B2_BUCKET_NAME`
2. If missing, restore from local backup instead

### Problem: "Backup file not found"
**Solution:**
1. Check the USB drive is inserted
2. Check the file name is correct
3. Check the path is correct

### Problem: "Permission denied"
**Solution:**
1. Add `sudo` before commands:
   ```bash
   sudo cp /home/pi/backup/.env /home/pi/BP-DragonFly-Garden/restaurant-system/backend/
   ```

### Problem: System not starting after restore
**Solution:**
1. Check the .env file:
   ```bash
   cat /home/pi/BP-DragonFly-Garden/restaurant-system/backend/.env
   ```
2. Make sure JWT_SECRET is set
3. Restart the service:
   ```bash
   sudo systemctl restart dragonfly-garden
   ```
