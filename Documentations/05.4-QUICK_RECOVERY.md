# 05.4 - QUICK RECOVERY CHECKLIST

> **This guide is for COMPLETE BEGINNERS. This is a step-by-step checklist for emergency situations.**

---

## 🚨 EMERGENCY CHECKLIST

### If the Pi SD card dies:

- [ ] Get the backup SD card
- [ ] Get a USB drive with backup files
- [ ] Insert backup SD card into Pi
- [ ] Power on the Pi
- [ ] Wait 2 minutes for startup
- [ ] Connect to "DragonflyHotspot" WiFi
- [ ] Open browser to `http://10.42.0.1:5000`
- [ ] Login to manager dashboard
- [ ] Test the printer
- [ ] System is running!

---

### If the Pi hardware dies:

- [ ] Get the laptop
- [ ] Connect the YHD-8390 printer to laptop
- [ ] Turn on the printer
- [ ] Open Command Prompt
- [ ] Type: `cd C:\BP-DragonFly-Garden\restaurant-system\backend`
- [ ] Type: `npm run start`
- [ ] Wait for "Server running on port 5000"
- [ ] Open browser to `http://localhost:5000`
- [ ] Login to manager dashboard
- [ ] Test the printer
- [ ] System is running!

---

### If the system won't start:

- [ ] Check the .env file exists
- [ ] Check JWT_SECRET is set in .env
- [ ] Check the database exists
- [ ] Check the printer is connected
- [ ] Type: `sudo systemctl status dragonfly-garden`
- [ ] If "inactive", type: `sudo systemctl start dragonfly-garden`
- [ ] If "failed", check the logs: `tail -f /home/pi/BP-DragonFly-Garden/restaurant-system/backend/server.log`

---

### If the printer won't work:

- [ ] Check USB cable connection
- [ ] Check printer is turned on
- [ ] Check printer has paper
- [ ] On Pi: Type `lpstat -p` to check printer status
- [ ] In manager dashboard: Go to Settings → Printer Management
- [ ] Click "Discover Printers"
- [ ] Select the printer
- [ ] Set Width to `48`
- [ ] Set Print Delay to `0`
- [ ] Check "Has Auto Cutter"
- [ ] Click "Save Printer Settings"
- [ ] Click "Test Print"

---

## 📋 QUICK COMMANDS

### On Pi:
```bash
# Check if system is running
sudo systemctl status dragonfly-garden

# Start the system
sudo systemctl start dragonfly-garden

# Stop the system
sudo systemctl stop dragonfly-garden

# Restart the system
sudo systemctl restart dragonfly-garden

# Check printer status
lpstat -p

# Restore from cloud backup
node src/restoreBackup.js

# See logs
tail -f /home/pi/BP-DragonFly-Garden/restaurant-system/backend/server.log
```

### On Laptop:
```cmd
# Go to backend folder
cd C:\BP-DragonFly-Garden\restaurant-system\backend

# Start the system
npm run start

# Install dependencies
npm install

# Build frontend
cd ..\..\frontend
npm run build
```
