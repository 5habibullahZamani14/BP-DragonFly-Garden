# 02.2 - NETWORK HOTSPOT SETUP GUIDE

> **This guide is for COMPLETE BEGINNERS. We will explain EVERYTHING step by step. This sets up the WiFi that customers connect to.**

---

## 🤔 WHAT IS A HOTSPOT?

A hotspot is like a WiFi network that the Pi creates. Customers connect to this WiFi to use the restaurant system.

- **Hotspot name (SSID):** `DragonflyHotspot`
- **Pi's IP address:** `10.42.0.1`
- **System address:** `http://10.42.0.1:5000`

When customers connect to this WiFi and open a browser, they automatically see the menu!

---

## 🔧 STEP 1: LOGIN TO YOUR PI

### What to do:
1. **Connect a monitor to the Pi**
   - Use HDMI cable
   - Connect to TV or computer monitor

2. **Connect a keyboard and mouse**
   - Use USB ports
   - Any keyboard and mouse will work

3. **Login**
   - Username: `pi` (or whatever you set)
   - Password: (whatever you set)
   - Type the password and press Enter
   - ⚠️ The password will not show stars or dots - this is normal!

---

## 💻 STEP 2: OPEN THE TERMINAL

### What to do:
1. **Click the black square icon**
   - On the top left of the screen
   - Says "Terminal" when you hover over it
   - This opens a black window

2. **Or right-click on the desktop**
   - Click "Accessories"
   - Click "Terminal"

---

## 📥 STEP 3: UPDATE THE SYSTEM

### What to do:
1. **Type this command exactly:**
   ```bash
   sudo apt update
   ```
   - Type it slowly
   - Press Enter
   - Type your password if asked
   - Wait for it to finish

2. **Type this command:**
   ```bash
   sudo apt upgrade -y
   ```
   - Press Enter
   - Wait 5-10 minutes
   - This updates all software

---

## 📥 STEP 4: INSTALL NETWORK MANAGER

### What to do:
1. **Type this command:**
   ```bash
   sudo apt install network-manager -y
   ```
   - Press Enter
   - Wait for it to finish

2. **Restart the Pi**
   ```bash
   sudo reboot
   ```
   - Press Enter
   - The Pi will restart
   - Wait for it to come back

---

## 🔌 STEP 5: CREATE THE HOTSPOT

### What to do:
1. **Login again after restart**

2. **Open Terminal again**

3. **Type this command:**
   ```bash
   sudo nmcli dev wifi hotspot ssid "DragonflyHotspot" password "yourpassword123"
   ```
   - Replace `yourpassword123` with a real password
   - ⚠️ Write this password down!
   - Press Enter

4. **Set the IP address to 10.42.0.1**
   ```bash
   sudo nmcli connection modify "DragonflyHotspot" 802-11-wireless.addr 10.42.0.1/24
   ```
   - Press Enter

5. **Restart NetworkManager**
   ```bash
   sudo systemctl restart NetworkManager
   ```
   - Press Enter

---

## ✅ STEP 6: TEST THE HOTSPOT

### What to do:
1. **On your phone**
   - Open WiFi settings
   - Look for "DragonflyHotspot"
   - Click on it
   - Enter the password you set

2. **Open a browser**
   - Chrome, Safari, or any browser
   - Type in the address bar:
   ```
   http://10.42.0.1:5000
   ```
   - Press Go/Enter

3. **You should see the restaurant system!**
   - If you see it, the hotspot works!
   - If not, check the next section

---

## 🔧 STEP 7: MAKE HOTSPOT START ON BOOT

### What to do:
1. **Type this command:**
   ```bash
   sudo systemctl enable NetworkManager
   ```
   - Press Enter

2. **The hotspot will now start automatically when the Pi turns on**

---

## ❓ TROUBLESHOOTING

### Problem: Can't find the hotspot on my phone
**Solution:**
1. Wait 1 minute after running the commands
2. Make sure you're not connected to another WiFi
3. Try turning WiFi off and on again on your phone

### Problem: Connected to hotspot but can't open the website
**Solution:**
1. Make sure the Pi is running the backend:
   ```bash
   sudo systemctl status dragonfly-garden
   ```
2. If it says "inactive", start it:
   ```bash
   sudo systemctl start dragonfly-garden
   ```

### Problem: Forgot the hotspot password
**Solution:**
1. Look on the Pi screen for a file called `.hotspot-password`
2. Or ask the manager
3. Or create a new hotspot with a new password:
   ```bash
   sudo nmcli dev wifi hotspot ssid "DragonflyHotspot" password "newpassword123"
   ```

### Problem: Need to change the hotspot name
**Solution:**
```bash
sudo nmcli dev wifi hotspot ssid "NewName" password "password123"
```

---

## 📋 IMPORTANT COMMANDS TO REMEMBER

| Command | What it does |
|---------|-------------|
| `sudo nmcli dev wifi hotspot ssid "DragonflyHotspot" password "password123"` | Create hotspot |
| `sudo systemctl restart NetworkManager` | Restart hotspot |
| `sudo systemctl status NetworkManager` | Check if hotspot is running |
| `ip addr show wlan0` | Show the IP address |
