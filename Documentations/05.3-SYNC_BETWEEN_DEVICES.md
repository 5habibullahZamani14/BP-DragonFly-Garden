# 05.3 - SYNC BETWEEN DEVICES

> **This guide is for COMPLETE BEGINNERS. We will explain EVERYTHING step by step. This shows you how to keep the Pi, backup SD, and laptop in sync.**

---

## 🤔 WHY DO YOU NEED TO SYNC?

You have THREE places with the system:
1. **The Pi** - The main server
2. **The backup SD card** - Spare SD card
3. **The laptop** - Backup server

### You need to keep them in sync because:
- If Pi SD dies, you need the backup SD to work
- If Pi dies, you need the laptop to work
- If you update one, you need to update all

---

## 🔄 THE SYNC PROCESS

### What to sync:
| File/Folder | What it contains |
|-------------|------------------|
| `.env` | Passwords and settings |
| `database.sqlite` | All your data |
| `menu-images/` | Menu pictures |
| `feedback-images/` | Feedback pictures |

### What NOT to sync:
| File/Folder | Why not |
|-------------|---------|
| `node_modules/` | Downloaded automatically |
| `.git/` | Git files, not needed |
| `logs/` | Just log files |
| `tmp/` | Temporary files |

---

## 💾 METHOD 1: ZIP FILE SYNC

### What to do:
1. **On the source device (Pi or laptop)**
   - Create a ZIP file with the important files

2. **Copy the ZIP to destination**
   - Use USB drive
   - Or email
   - Or cloud storage (OneDrive, WhatsApp, etc.)

3. **Extract on destination**
   - Extract to the right folders

---

## 📦 STEP 1: CREATE SYNC ZIP (ON SOURCE)

### On the Pi:
1. **Open Terminal**

2. **Type these commands:**
   ```bash
   cd /home/pi
   mkdir -p sync-temp
   cp /home/pi/BP-DragonFly-Garden/restaurant-system/backend/.env sync-temp/
   cp /home/pi/BP-DragonFly-Garden/restaurant-system/backend/src/database/database.sqlite sync-temp/
   cp -r /home/pi/BP-DragonFly-Garden/frontend/public/menu-images sync-temp/
   cp -r /home/pi/BP-DragonFly-Garden/frontend/public/feedback-images sync-temp/
   tar -czf dragonfly-sync-$(date +%Y%m%d).tar.gz -C sync-temp .
   rm -rf sync-temp
   ```

3. **Find the ZIP file:**
   ```bash
   ls -la dragonfly-sync-*.tar.gz
   ```

---

## 💿 STEP 2: COPY ZIP TO DESTINATION

### What to do:
1. **Insert USB drive into source device**

2. **Copy the ZIP file to USB drive**
   - Drag and drop
   - Or use file manager

3. **Safely eject USB drive**
   - Right-click → Eject

4. **Insert USB drive into destination device**

---

## 📂 STEP 3: EXTRACT ZIP (ON DESTINATION)

### On the destination (Pi or laptop):

### For Pi:
```bash
cd /home/pi
tar -xzf /media/pi/USB_NAME/dragonfly-sync-DATE.tar.gz
cp .env /home/pi/BP-DragonFly-Garden/restaurant-system/backend/
cp database.sqlite /home/pi/BP-DragonFly-Garden/restaurant-system/backend/src/database/
cp -r menu-images /home/pi/BP-DragonFly-Garden/frontend/public/
cp -r feedback-images /home/pi/BP-DragonFly-Garden/frontend/public/
```

### For Laptop:
```cmd
cd C:\BP-DragonFly-Garden\restaurant-system\backend
copy C:\USB_PATH\.env .
copy C:\USB_PATH\database.sqlite src\database\
xcopy /E /I C:\USB_PATH\menu-images ..\..\frontend\public\menu-images\
xcopy /E /I C:\USB_PATH\feedback-images ..\..\frontend\public\feedback-images\
```

---

## 🔁 METHOD 2: DIRECT COPY (USB DRIVE)

### What to do:
1. **On source device, copy files to USB drive**

2. **On destination device, copy from USB drive**

### Files to copy:
- `.env`
- `database.sqlite`
- `menu-images/` folder
- `feedback-images/` folder

## 🔄 WHEN TO SYNC

### Sync after:
- [ ] Adding new menu items
- [ ] Changing menu prices
- [ ] Adding new employees
- [ ] Changing settings
- [ ] Any important data changes

### Sync before:
- [ ] Going on vacation
- [ ] SD card might die
- [ ] Pi might break

## ❓ TROUBLESHOOTING

### Problem: "File already exists" error
**Solution:**
- Overwrite the files
- The new files are the correct ones

### Problem: "Permission denied"
**Solution:**
- Add `sudo` on Pi
- Run as Administrator on Windows

### Problem: Database not updating
**Solution:**
1. Stop the system first:
   ```bash
   sudo systemctl stop dragonfly-garden
   ```
2. Copy the database
3. Start the system:
   ```bash
   sudo systemctl start dragonfly-garden
   ```

### Problem: Images not showing
**Solution:**
1. Check the folder names are correct
2. Check the files are in the right place
3. Clear browser cache
