# Raspberry Pi printer setup reference

Use the maintained [Linux/CUPS printer setup guide](../02.3-PRINTER_SETUP.md) and
[printer troubleshooting guide](../04-PRINTER_TROUBLESHOOTING.md). Older instructions
that configure raw ESC/POS output or claim that a profile setting guarantees auto-cut
are not accurate for the current Linux plain-text `lp` print path.
