# Raspberry Pi printer setup reference

This older internship reference is not current deployment guidance. Follow the
maintained [Linux/CUPS printer setup guide](../../02.3-PRINTER_SETUP.md) and
[troubleshooting guide](../../04-PRINTER_TROUBLESHOOTING.md). In particular, do not
assume a raw ESC/POS queue or an app profile's cutter setting is supported by the current
Linux print path.
