# 03.2 - PRINTER SETUP (WINDOWS LAPTOP)

> **This guide is for COMPLETE BEGINNERS. We will explain EVERYTHING step by step. This connects the YHD-8390 printer to your Windows laptop.**

---

## 🤔 WHY IS PRINTER SETUP DIFFERENT ON WINDOWS?

On Windows, the printer works differently than on the Pi:

- **On Pi:** Uses CUPS (Linux printing system)
- **On Windows:** Uses Windows printing + `print_gdi.exe`
- **The `print_gdi.exe` file:** Sends raw commands to the printer

---

## 🔌 STEP 1: CONNECT THE PRINTER

### What to do:
1. **Find the USB cable**
   - It came with the YHD-8390 printer
   - One end is USB-A (normal USB)
   - One end is USB-B (square USB, goes into printer)

2. **Plug the USB cable**
   - USB-B end → into the printer
   - USB-A end → into your laptop
   - Turn on the printer
   - The power light should be on

3. **Windows should detect the printer**
   - A message may appear: "Setting up device"
   - Wait for it to finish

---

## 🖨️ STEP 2: INSTALL THE PRINTER DRIVER

### What to do:
1. **If Windows installed the driver automatically**
   - Great! Skip to Step 3

2. **If Windows didn't install the driver**
   - Insert the CD that came with the printer
   - Or download from the manufacturer website
   - Run the installer
   - Follow the steps

3. **⚠️ IMPORTANT: Use the correct driver**
   - **DO NOT** use the POS-80C driver (it has margins)
   - **DO** use the generic/text-only driver
   - Or let Windows auto-install

---

## 🔗 STEP 3: ENABLE PRINTER SHARING

### What to do:
1. **Open Settings**
   - Click Start button (Windows logo)
   - Type "Settings"
   - Click the gear icon

2. **Click "Bluetooth & devices"**
   - On the left side
   - Click "Printers & scanners"

3. **Find your printer**
   - Look for "YHD-8390" or similar
   - Click on it

4. **Click "Manage"**
   - Click "Printer properties"

5. **Click "Sharing" tab**
   - At the top of the window

6. **Check "Share this printer"**
   - Check the box
   - Note the "Share name" (usually the same as printer name)

7. **Click "Apply"**
   - Then click "OK"

---

## ⚙️ STEP 4: CONFIGURE IN THE RESTAURANT SYSTEM

### What to do:
1. **Start the backend on your laptop**
   - Open Command Prompt
   - Type:
   ```
   cd C:\BP-DragonFly-Garden\restaurant-system\backend
   npm run start
   ```
   - Press Enter
   - Wait for "Server running on port 5000"

2. **Open the restaurant system**
   - Open Chrome or Edge
   - Type in the address bar:
   ```
   http://localhost:5000
   ```
   - Press Enter

3. **Login as manager**
   - Click "Manager Login"
   - Enter username and password

4. **Go to Settings → Printer Management**
   - Click "Settings" in the menu
   - Click "Printer Management"

5. **Click "Discover Printers"**
   - The system will find your printer

6. **Select the printer**
   - Click on "YHD-8390" in the dropdown

7. **Set printer settings**
   - **Width:** `48` (for 80mm paper)
   - **Print Delay:** `0` (for auto-cutter)
   - **Empty Lines Before:** `2`
   - **Empty Lines After:** `3`
   - **Has Auto Cutter:** `Yes` (check the box)

8. **Click "Save Printer Settings"**
   - This saves the configuration

9. **Click "Test Print"**
   - The printer should print a test ticket
   - It should use full width
   - It should cut the paper automatically

---

## 📁 STEP 5: CHECK print_gdi.exe

### What to do:
1. **Make sure `print_gdi.exe` is in the right place**
   - It should be at:
   ```
   C:\BP-DragonFly-Garden\print_gdi.exe
   ```

2. **If it's not there**
   - Copy it from the Pi
   - Or ask the manager for a copy

3. **This file is needed for raw ESC/POS commands**
   - It sends the cut command to the printer
   - It sends the width command to the printer

---

## ❓ TROUBLESHOOTING

### Problem: Printer not found in "Discover Printers"
**Solution:**
1. Check the USB cable connection
2. Check if printer is turned on
3. Check if printer sharing is enabled
4. Restart the backend:
   ```
   Ctrl + C
   npm run start
   ```

### Problem: Test print works but no auto-cut
**Solution:**
1. Make sure "Has Auto Cutter" is checked
2. Make sure "Print Delay" is 0
3. Check that `print_gdi.exe` is in the right place

### Problem: Prints with huge margins
**Solution:**
1. Make sure you're using the generic driver, NOT POS-80C
2. Make sure Width is set to 48
3. The system uses ESC/POS to bypass Windows margins

### Problem: "print_gdi.exe not found" error
**Solution:**
1. Make sure the file is at:
   ```
   C:\BP-DragonFly-Garden\print_gdi.exe
   ```
2. Copy it from the Pi if missing
